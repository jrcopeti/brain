# Global rules found in trip-planner's AGENTS.md

Most of trip-planner's `AGENTS.md` is not about trip-planner. Its working rules hold for every
project: stage the work and stop until a commit is asked for after the diff exists, one branch
in the main tree (no worktree), small one-concern PRs split before coding, green checks before
staging, terse descriptions and comments, and a plan plus devlog per piece of work.

Why it matters: these are candidates for global guidelines, so no repo has to repeat them. Each
becomes a guideline only when the user states it.
